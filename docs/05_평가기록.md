`eval/out/` 은 작업 중 임시 출력이라 추적하지 않는다 — 보고서에 쓸 실행만 `results/` 로 옮긴다.

측정 방법은 `docs/02` §부록 3번. 요약하면: golden 20건 × n회, 혼동행렬 2개(신호등·편차), abAgree 정확도,
자기일관성(같은 입력 n회가 전부 같은 답인가). 베이스라인은 LLM 없이 토큰 겹침(Jaccard)으로 답하는 mock.

## 2026-10-14 · v2 → v3

**v2 오판 6건**을 읽고 둘로 갈랐다.

| 건 | v2 결과 | 원인 분류 | 조치 |
|---|---|---|---|
| g05 "한 1억 5천?" | match 를 minor 로 (물음표를 유보로 읽음) | **프롬프트** | v3: 구어체 완화는 유보가 아님을 명시 → ✅ 고쳐짐 |
| g09 "일부는 ETF 해도 될 것 같은데" | minor 를 major 로 | **프롬프트** | v3: 부분적·시험적 제안은 흔들림(minor)임을 명시 → ✅ 고쳐짐 |
| g10 "지금 반은 코인이에요" | major 를 minor 로 (성향 서술에 맞춰 읽음) | **프롬프트 + 라벨** | v3: 합의가 기준임을 명시 → ❌ 여전히 minor. 모델의 사유: "반은 코인이 주택자금인지 불분명" — 타당한 지적 |
| g02 아내 "없어요" | abAgree 를 true 로 | **라벨 판단** | 보류. "없어요"가 남편의 승진을 부정한 것인가, 모르는 것인가 |
| g13 "무리해서라도" / "감당 가능한 선" | abAgree 를 true 로, A 를 match 로 | **라벨 판단** | 보류. 성향 차이를 🟡로 볼지 🟢로 볼지 — 처음부터 "기록용"이었던 케이스 |
| g18 "연봉 동결" | B 를 match 로 | **라벨 판단** | 보류. v3에서는 A·B 둘 다 match → 🟢 (신호등까지 틀어짐). "동결"과 "물가 수준 상승"이 다른 값인가 |

**v3 변경 (프롬프트 규칙 3줄 추가, 케이스를 지목하지 않는 일반 규칙으로):**
1. 전제에 합의 사항이 있으면 합의가 기준. 성향·선호 서술은 배경
2. 구어체 완화("~?", "정도", "쯤")는 유보가 아님. 유보는 값을 정하지 않은 경우
3. 부분적·시험적 제안은 minor. major 는 다른 결정을 내렸거나 전제를 명시 부정할 때

**결과:** 2건 고쳐지고(g05·g09) 1건 틀어짐(g18). 신호등 16 → 18. 중간 라벨 35 → 37.

**정직하게 적어둘 것:**
- v3 규칙은 **이 20건을 보고 만들었다.** 같은 20건으로 잰 90%는 과적합이 섞여 있다. 믿을 수 있는 숫자가
  되려면 규칙을 만들 때 보지 않은 케이스가 필요하다 → 다음 할 일 1번.
- 남은 오판 4건은 전부 라벨이 다툼의 여지가 있는 건이다. **라벨은 모델에 맞춰 고치지 않는다.**
  재무설계사(도메인)가 "이 상황을 🟡로 볼 것인가"를 정하고, 그 근거를 `note` 에 적는다.
  이게 docs/02 가 말하는 전문가 라벨이다.
- 자기일관성 20/20 두 번 연속. temperature 를 못 박을 수 없는 모델인데도(docs/02) 흔들리지 않았다.

## 2026-10-14 (오후) · 미학습 10건 추가 + 라벨 정정 3건 → v3 재측정

**라벨 정정** — 기준은 모델이 아니라 규칙서(docs/02)와의 일관성. 전부 `note` 에 이유를 남겼다.
- g02 abAgree false→true ("없어요"는 자기 계획이지 상대 승진의 부정이 아님)
- g13 🟡→🟢 (전제가 이미 성향 차이를 담고 있고 합의를 부정하는 답이 없음)
- g18 🟡→🟢 ("동결"은 "큰 인상 없음"과 같은 방향)
- g10 유지 🔴 ("모아둔 돈"=주택자금, 절반 코인은 합의 위반)

승진 제안 거절(키워드 함정), 용돈 범위 주식, 채권 ETF 제안, 합의 위반+항의, 유보적 추가 지원.
