## 팀이 정할 것

1. **새 부부는 데모 부부의 "지금" 카드를 복사한다.** 10.16 먼저 묻기 시연에서 데모 부부의 "승진·이직"을 "2027년 상반기 이직"으로 바꿔서,
   그 뒤 등록한 새 부부도 전부 "이직" 전제로 시작한다. A안 템플릿(`docs/09`)이 들어오면 사라질 문제다. **그 전까지 데모 부부(김현우·박지우) 카드는 더 바꾸지 않는 게 안전.**
2. **테스트 부부가 목록에 남는다.** "E2E 자동테스트 …" 5쌍, "1234" 1쌍. 부부는 지울 수 없게 만들었다(이력 보존). 목록에서 숨기는 표시를 만들지, 시연 전에 DB 를 새로 깔지.
3. **부부 화면 문구 세 곳이 실제 동작과 다르다.**
   - 전달 화면 "다음 맞춰보기 · 11월 둘째 주쯤 알려드릴게요" — 날짜가 고정 문구다.
   - "바뀐 게 있으면 [내 설계]에서 알려주세요" — [내 설계]에 알리는 기능이 없다.
   - 열린 맞춰보기가 없을 때도 제목이 "세 가지만 맞춰볼게요".
4. **[내 설계]는 카드 5장만 보인다.** 테스트 부부는 12장. 의도(핵심만)인지, 전부 보여줄지.
5. **설계사 콘솔을 처음 열면 예시 부부 4쌍이 1초쯤 보였다가 실제 목록으로 바뀐다.** 심사 시연 중이면 헷갈릴 수 있다. "불러오는 중"으로 바꿀지.

## 브라우저로 본 것 (로컬 + 실 DB)

- **설계사:** 코드 입력 → 부부 목록 → 가정 카드 → [카드 추가] 시점형, "→ 2027년 3월" 미리보기, 바로 묻기 → 처리 대기(요약 3줄) → 변경 이력.
- **부부 폰 (375px):** 링크로 입장(코드 자동 채움) → "설계사님이 두 분께 따로 여쭤볼 게 있어요 · 정기 1문항" → 연·월 고르기 → 제출 → "전달됐어요" → [내 설계].
- **먼저 묻기 실패 화면:** 값 수정 → 두 분 다른 답 → 카드에 "동의 안 됨" 칩, 안내 문구, "v3 저장" 버튼 살아 있음.
