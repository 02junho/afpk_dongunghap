# 19. 카드 골라 맞춰보기 열기 — 화면 설계안 (11.04)

> 아직 만들지 않았다. 이 안으로 정하면 반나절에 만든다.
> **11.04 결정: 맞춰보기는 무조건 3문항.** 앱은 카드를 추천하지 않는다 — 무엇을 물을지는 설계사가 고른다. 아래 "우리 의견"은 팀에 드리는 의견이고, AI의 제안이 아니다.
> 왜 필요한지는 `docs/11_화면흐름도.pdf` 8쪽.

## 한 줄로

설계사가 **질문 카드 화면에서 물어볼 카드 3장에 체크하고 "맞춰보기 열기"**를 누르면, 두 분 폰에 그 카드들로 맞춰보기가 열린다.
판정 · 처리 대기 · 부부 화면은 지금과 같다. AI는 쓰지 않는다.

## 어디에 두나 — 질문 카드 화면

카드 목록이 이미 있는 곳이라 새 화면을 만들지 않는다. 맨 위 버튼 줄에 하나를 더한다.

```
질문 카드 · 에이피 · 에피케
[카드 추가]  [엑셀로 만들기]  [엑셀 다시 읽기]  [맞춰보기 열기]   ← 새 버튼
```

처리 대기 화면의 "맞춰보기 새로 열기"는 이 화면으로 오게 바꾼다 (같은 일을 하는 버튼이 두 곳에 따로 있지 않게).

## 화면 모양

"맞춰보기 열기"를 누르면 왼쪽 카드 목록에 체크 칸이 생기고, 오른쪽에 고른 카드가 모인다.

```
┌ 왼쪽: 카드 목록 ─────────────────┐  ┌ 오른쪽: 맞춰보기 열기 ─────────────────┐
│ 소득·직업                         │  │ 고른 카드 3장 · 두 분 각자 약 3분       │
│ ☑ 남편 연 급여(세전)   6,700만원   │  │                                        │
│ ☐ 아내 연 매출         4,000만원   │  │  1  남편 연 급여(세전) · 6,700만원      │
│                                   │  │  2  월세 (1년) · 1,140만원              │
│ 주거                              │  │  3  보증금 · 2,000만원                  │
│ ☑ 월세 (1년)           1,140만원   │  │                                        │
│ ☑ 보증금               2,000만원   │  │ 두 분 폰에는 이렇게 나갑니다 (1번)      │
│ ☐ 청약저축 납입 (1년)    120만원   │  │ ┌────────────────────────────────┐   │
│                                   │  │ │ 설계사님과 정한 계획             │   │
│ 저축·투자                         │  │ │ 남편 연 급여(세전) · 6,700만원   │   │
│ ☐ 적금 (1년)             500만원   │  │ │ 지금도 그렇게 생각하시나요?      │   │
│ ...                               │  │ └────────────────────────────────┘   │
│                                   │  │                                        │
│                                   │  │ [고른 3장으로 맞춰보기 열기]  [취소]   │
└───────────────────────────────────┘  └────────────────────────────────────────┘
```

- 카드 줄을 누르면 체크가 켜지고 꺼진다. 오른쪽 목록은 **주제 순서**(주거 → 소득 → …)로 정렬된다. 부부 폰에 나가는 순서도 같다.
- 오른쪽 "두 분 폰에는 이렇게 나갑니다"는 지금 카드 화면에 있는 미리보기를 그대로 쓴다.
- **정확히 3장을 골라야 버튼이 켜진다.** 3장을 고르면 나머지 체크 칸은 잠기고, "3장을 모두 골랐습니다"가 보인다. 하나를 빼면 다시 고를 수 있다.
- 오른쪽 위에 "0 / 3장" … "3 / 3장"으로 몇 장 골랐는지 보인다.

## 연 뒤에

```
✓ 정기 맞춰보기를 열었습니다 · 3문항
   두 분 폰 홈에 빨간 점이 켜집니다.   [알림 문구 복사]
```

- 앱은 부부에게 알림을 보내지 않는다(지금도 그렇다). 그래서 **카톡에 붙여 넣을 짧은 문구**를 복사하게 한다.
  > [돈궁합] 에이피 · 에피케 님, 맞춰보기가 열렸어요. 앱에서 3문항(약 3분) 답해 주세요. https://afpk-dongunghap.vercel.app/c/join?code=······
- 왼쪽 카드 목록의 체크 칸은 사라지고, 고른 카드 옆에 "묻는 중" 표시가 붙는다.

## 정해 둘 규칙

| 규칙 | 우리 의견 | 이유 |
|---|---|---|
| 한 번에 몇 장 | **무조건 3장** (11.04 결정) | 두 분 각자 3분이면 끝난다. 매번 같은 길이라 부부가 부담을 예상할 수 있다 |
| 이미 열린 맞춰보기가 있으면 | 열지 않는다. 버튼 자리에 "진행 중인 맞춰보기(남편 3/3 · 아내 1/3)가 끝난 뒤 열 수 있습니다" | 부부 폰에 맞춰보기가 두 개면 헷갈린다. 지금 다른 버튼들과 같은 규칙 |
| 부부 폰에 보이는 이름 | 처음이면 **"첫 맞춰보기"**, 그다음부터 **"정기 맞춰보기"** | 지금 부부 화면에 있는 이름 그대로 |
| 앱이 카드를 추천하나 | **추천하지 않는다.** 대신 카드마다 **"마지막으로 물은 날"**만 작게 보여 준다 (예: "아직 안 물음", "10월 23일 · 🟢") | 무엇을 물을지는 설계사가 정한다. 날짜는 고를 때 참고만 |
| 연습용 카드 10장 부부 | 지금처럼 등록할 때 3문항이 자동으로 열린다. 그다음부터는 이 화면으로 | 팀원 연습 부부가 그대로 쓰인다 |

## 부부 화면은 바뀌지 않는다

부부 홈에 "이제부터 시작할게요 · 정기 맞춰보기 3문항"이 뜨고, 지금과 똑같이 답한다.
남편이 다 답하면 "답을 모두 보냈어요 · 아내님 차례예요"가 뜬다 (11.04에 고친 화면).

## 정할 것 (팀)

1. 이 모양으로 만들까?
2. ~~한 번에 최대 몇 장?~~ → **3장 고정으로 정함 (11.04)**
3. "마지막으로 물은 날" 표시를 넣을까? (우리 의견: 넣는다)
4. "알림 문구 복사" 버튼을 넣을까? (우리 의견: 넣는다)
5. **지금 1문항으로 여는 두 곳**(처리 대기 "두 분께 같이 묻기", 카드 추가의 "바로 묻기")도 3문항에 맞출까? — 아래 참고

## 3문항 고정과 맞지 않는 곳 (11.04 확인)

지금 앱에는 **1문항짜리 맞춰보기를 여는 곳이 두 군데** 있다.

| 어디 | 지금 | 3문항 고정이면 |
|---|---|---|
| 처리 대기 "먼저 알린 변화" → **두 분께 같이 묻기** | 그 카드 1장으로 바로 열림 | 가. 이 버튼을 누르면 카드 골라 열기 화면으로 가고, 그 카드가 미리 체크돼 있다. 나머지 2장을 설계사가 더 고른다 (우리 의견) |
| | | 나. 이 경우만 1문항 예외로 둔다 |
| 카드 추가 → **"저장하고 이 카드 한 장을 두 분께 바로 묻기"** | 새 카드 1장으로 바로 열림 | 이 체크를 없앤다. 새 카드는 다음에 3장을 고를 때 같이 고른다 (우리 의견) |
