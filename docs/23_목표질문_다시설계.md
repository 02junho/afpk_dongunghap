# 23. 목표 질문으로 다시 설계 (2026-11-05 결정 · 11.09 앱에 넣음 — 질문은 팀 확정 전 초안)

> **11.05 사용자 결정 (팀원 제안 반영)**
> 1. 부부에게 **계획 값을 보여 주지 않는다.** 빈칸으로 묻는다. (10.23 팀 결정 "기존 설계를 보여 주고 지금도 그렇게?"를 바꾼다)
> 2. 질문은 **목표 말투**로 묻는다 — "○○는 얼마를 원하나요? / 어떻게 하고 싶나요?"
> 3. 질문 틀 30개는 **모든 고객에게 고정**. 고객마다 바뀌는 건 **계획 값 하나뿐**이고, 재무설계 결과에서 가져온다.
> 4. 팀이 나중에 질문 30개를 주면 **그 틀 그대로** 앱에 들어가게 한다 → 6절 양식.
> 5. 문서끼리 다른 값(※)은 **팀 방침: 먼저 뽑아 보고 나중에 맞춘다.**
> 6. **맞지 않는 질문은 건너뛰지 않고 "해당 없음"** (11.05 사용자 결정 A). 모든 질문에 "해당 없음" 보기가 붙고, 설계사가 정답지에 "해당 없음"을 넣을 수 있다. 건너뛰면 나중에 생긴 계획(아이 계획 없음 → 1~2년 안)을 못 잡는다.
>
> 팀 검토용 Google 문서: 공유 드라이브 04. 앱 설계 › "11.5 목표 질문 틀 30문항 (초안)" — 5절 표를 팀원 예시 모양 `질문 [이 고객 값] → 답 모양` 으로 옮겼다. 이전 "11.5 질문 틀 30문항 (수정안)"은 휴지통.
> 팀 문서에는 **찾을 곳 칸을 넣지 않는다** — AI에게 주는 안내라 앱 담당이 `template.ts` 의 `find` 에 "무엇을 찾을지"로 적는다 (팀 문서 이름 금지: 다른 설계사 문서엔 없다). 질문 쓰는 규칙 · 바뀐 것 단락도 팀 문서에서 지워졌다(11.05 팀 편집) → 규칙은 이 문서 4절에만.

## 1. 흐름

```
① 계획 값 정하기   재무설계 결과 올림 → AI가 질문마다 값을 찾음 → 설계사가 원문과 대조해 확인
                   예) 3-3 은퇴 후 생활비 → 월 300만 원
                          ↓  (부부에게는 안 보임)
② 매주 질문        그 주 테마 5문항을 남편 · 아내 폰에 따로
                   "은퇴 후 한 달 생활비는 얼마를 원하나요?"   [ 350 ] 만 원 / 매달
                          ↓
③ 비교 (규칙)      계획 300만 ↔ 남편 300만 · 아내 350만  →  🔴
                          ↓
④ 설계사 화면      "은퇴 후 생활비 — 계획 300만 · 남편 300만 · 아내 350만"  →  상담
                   부부 화면에는 판정 · 상대 답이 안 나온다 (그대로)
```

## 2. 부부 폰 화면

계획 값 · "그대로예요 / 바뀌었어요" 버튼이 **없어진다.** 질문과 답 칸만 있다.

| 답 모양 | 화면 | 예 |
|---|---|---|
| 보기 | 보기 버튼 (모든 고객 같은 목록) + 아직 모름 + 말로 적기 | 집 마련 방법: 청약을 먼저 / 기존 집을 산다 / 전세 · 월세로 / 아직 모름 |
| 금액 | 숫자 칸 + **만 원** + (매달 / 매년 / 한 번) 표시 | [ 300 ] 만 원 / 매달 |
| 나이 · 개월 · 명 · 년 · % | 숫자 칸 + 단위 | [ 60 ] 세 |
| 연도 | 연도 칸 | [ 2032 ] 년 |

모든 질문에 **"아직 모름"** · **"해당 없음"** · **"말로 적기"** 가 있다.

## 3. 판정 (지금 규칙 그대로)

| 답 | 판정 | 누가 |
|---|---|---|
| 계획 값과 같다 (둘 다) | 🟢 | 규칙 |
| 한 분이라도 다르다 · "아직 모름" | 🔴 | 규칙 |
| 정답지 "해당 없음" ↔ 답 "해당 없음" | 🟢 · 다른 답이면 🔴 (새 계획이 생김) | 규칙 |
| "말로 적기" → 숫자 · 보기로 읽힘 | 같으면 🟢 · 다르면 🔴 | AI가 읽고 규칙이 비교 |
| "말로 적기" → 못 읽음 | 🟡 설계사 확인 | — |

- 허용 범위 없음 (11.05) 그대로. 1만 원만 달라도 🔴.
- 보여 주지 않으니 **기억이 다르면 🔴** 가 된다. 이게 이 방식의 목적이다 — "둘이 같은 목표를 기억하고 있나"를 본다. 보여 주면 "네"를 누르기 쉽다.
- 대신 🔴가 늘 수 있다. 설계사 화면에 계획 · 남편 · 아내 값이 나란히 나오니 설계사가 "기억 차이"인지 "생각이 바뀐 것"인지 판단한다.

## 4. 질문 쓰기 규칙 (팀원에게 전할 것)

1. **목표 말투**로 쓴다. "○○는 얼마를 원하나요? / 어떻게 하고 싶나요? / 언제쯤 하고 싶나요?"
2. **한 질문에 한 가지만** 묻는다. (주택 · 노후 자금을 한 질문에 ✗)
3. **질문과 보기에 이 고객만의 말을 넣지 않는다.** 숫자 · 시기 · 이름 · "아내 방식" 같은 말은 모두 "이 고객 값" 칸으로.
4. 답 모양은 **보기 · 금액(매달 / 매년 / 한 번) · 나이 · 개월 · 명 · 년 · % · 연도** 중 하나.
5. **보기는 모든 고객에게 같은 목록.** 서로 겹치지 않게. "아직 모름" · "해당 없음"은 앱이 붙인다. 이 고객 값은 반드시 보기 중 하나.
6. 예 / 아니오 대신 **"무엇을 하고 싶은지"** 를 보기로. (동의하나요? ✗ → 늘린다 / 그대로 / 줄인다)
7. **부부가 외워서 답할 수 있는 숫자만** 묻는다. 빈칸으로 묻기 때문에 "월 153,988원" 같은 계산 결과는 아무도 못 맞힌다 → 보기로 바꾸거나 빼기. 금액은 **만 원 단위**로 떨어지는 목표만.
8. **재무설계 결과에 답이 적혀 있는 것**만 묻는다.

## 5. 30문항 초안 (목표 말투 · 규칙 4절 적용)

"이 고객 값"은 지금 4단계 초안에서 찾은 값. ⚠ = 문서끼리 다르거나 없음.

### 1주 · 주택
| # | 질문 | 답 모양 | 이 고객 값 |
|---|---|---|---|
| 1-1 | 집은 어떤 방법으로 마련하고 싶나요? | 보기: 청약을 먼저 노린다 / 기존 집을 산다 / 전세 · 월세로 지낸다 | 청약을 먼저 노린다 |
| 1-2 | 마련하고 싶은 집값은 얼마인가요? | 금액 (한 번) | 4억 8,000만 원 |
| 1-3 | 내 집은 언제쯤 마련하고 싶나요? | 연도 | 2032년 |
| 1-4 | 집 살 때 대출은 최대 얼마까지 받을 생각인가요? | 금액 (한 번) | 3억 3,000만 원 |
| 1-5 | 집 마련을 위해 한 달에 얼마씩 모으고 싶나요? | 금액 (매달) | 120만 원 (지금 시기 · 2028년 60만 → 2029년 130만) |

| 2-3 | 출산 뒤 일은 몇 개월 쉬고 싶나요? | 개월 | ⚠ 6개월 (2단계 · 출산) ↔ 1년 (3단계) ↔ 2년 (보험) |

## 6. 팀이 30개를 줄 때 양식

팀원은 이 칸만 채우면 된다. 이대로 앱의 질문 틀(`src/data/template.ts`)이 된다.

| 칸 | 설명 | 고정? |
|---|---|---|
| 번호 · 테마 | 1-1 … 6-5 | 고정 |
| 질문 | 목표 말투, 고객 정보 없이 | 고정 |
| 답 모양 | 보기 / 금액(매달 · 매년 · 한 번) / 나이 / 개월 / 명 / 년 / % / 연도 | 고정 |
| 보기 | 답 모양이 보기일 때만. 모든 고객 같은 목록 | 고정 |
| 찾을 곳 | 재무설계 결과의 어느 부분에서 값을 찾나 ("부동산 — 목표 집값") | 고정 |
| 이 고객 값 | 지금 고객의 값 — 시연 · 테스트용 예시 | **고객마다** |

"이 계획이 바뀌면 생기는 일"(AI 요약용 한 줄)은 앱 담당이 적는다.

## 7. 앱에서 바뀌는 것 (반영할 때 한 번에)

- 부부 질문 화면: 계획 말풍선 · "그대로예요 / 바뀌었어요" 빼고, 질문 + 답 칸 (보기 버튼 / 숫자 칸).
- 다른 답 후보(`src/lib/answer-options.ts`)는 부부 화면에서 안 쓴다 — 후보가 계획 값에서 나와서 답을 알려 주게 된다.
- 판정 규칙(`src/judge/deterministic.ts`)은 그대로. 새 단위 "년"(대출 기간) · 연도만 받는 칸 추가.
- **"해당 없음"**: 모든 칸의 보기에 자동으로 붙인다("아직 모름"처럼). 숫자 · 연도 칸도 계획 값으로 "해당 없음"을 받게 한다(지금은 숫자 칸 보기를 고르면 늘 🔴). 설계사 질문 틀 화면에 "해당 없음" 버튼. AI 값 찾기는 "해당 없음"을 내지 않는다 — 문서에 없으면 빈칸, 판단은 설계사.
- 설계사 화면: "그대로예요 / 바뀜" 대신 **계획 · 남편 · 아내 값 나란히**.
- 값 찾기 프롬프트(extract) · 판별 프롬프트에 질문이 들어가므로 `PROMPT_VERSIONS` 올림.
- 문서: CLAUDE.md(객관식 · 다른 답 후보 규칙), docs/20 · 00 · 06 · 13 · 15, 흐름도 · 테스트 안내 다시 만들기. 10.23 팀 결정을 이 결정으로 바꿨다고 docs/00 에 적기.
