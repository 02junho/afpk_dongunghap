# 돈궁합 테스트 안내 (11.9)

질문 방식이 바뀌었습니다. 이제 부부에게 재무설계 결과의 계획 값을 보여 주지 않고, "은퇴 후 한 달 생활비는 얼마를 원하나요?"처럼 목표를 묻습니다. 두 사람이 답한 값이 계획과 다르면 설계사에게 올라갑니다. 두 명이 한 조로 25분쯤 걸립니다.

## 준비물

- 폰 2대: 한 명은 남편, 한 명은 아내로 들어갑니다
- 컴퓨터 1대 (크롬): 설계사 화면
- 설계사 코드: 준호에게 따로 받습니다

| 조 | 연습 부부 | 입장 코드 | 쓰는 사람 |
|---|---|---|---|
| 1조 | 팀원 연습 1 | 242311 |  |
| 2조 | 팀원 연습 2 | 739899 |  |

> 두 연습 부부 모두 새 질문 30칸이 예시 값으로 채워져 있고 사이클은 아직 시작 전입니다. 다른 조의 코드로 들어가지 마세요. 같은 역할로 두 명이 들어오면 나중에 들어온 사람이 자리를 가져갑니다.

## 이번에 바뀐 것

### 1. 계획 값을 보여 주지 않고 목표를 묻는다

예전에는 "설계사님과 정한 계획: 2032년 6월. 지금도 그렇게 생각하시나요?"라고 물었습니다. 이렇게 물으면 대부분 "네"를 눌러서, 두 사람이 정말 같은 목표를 기억하는지 알 수 없었습니다. 지금은 질문만 나오고 계획 값은 보이지 않습니다.

### 2. 답하는 방법

| 질문 종류 | 답하는 방법 |
|---|---|
| 보기 질문 (예: 주택자금은 어디에 두고 싶나요?) | 보기에서 고릅니다. 보기는 모든 고객이 같습니다 |
| 숫자 질문 (예: 마련하고 싶은 집값은 얼마인가요?) | 숫자를 적습니다. 금액은 만 원 단위입니다. "48000"이라고 적어도 되고 "4억 8천"이라고 적어도 됩니다. 아래에 "= 4억 8,000만원"처럼 읽은 값이 나옵니다 |
| 모든 질문 | 아직 모름 · 해당 없음 · 말로 적기가 함께 있습니다 |

### 3. 해당 없음

아이 계획이 없는 부부에게 출산 질문처럼, 고객에게 맞지 않는 질문이 있습니다. 이런 질문은 건너뛰지 않고 설계사가 질문 틀에서 정답을 "해당 없음"으로 정합니다. 부부도 "해당 없음"을 고르면 계획 그대로이고, 나중에 계획이 생겨 다른 답을 고르면 설계사에게 올라갑니다.

### 4. 설계사 화면

처리 대기에서 계획 값, 남편 답, 아내 답이 나란히 보이고, 답마다 "계획과 같음" 또는 "다름"이 붙습니다. 질문 틀에서는 숫자 칸 옆 "해당 없음" 버튼으로 정답을 해당 없음으로 바꿀 수 있습니다.

## 시험할 때 쓰는 정답

## 테스트 순서

### 1단계. 준비

1. 남편 폰과 아내 폰에서 사파리(아이폰) 또는 크롬(안드로이드)으로 afpk-dongunghap.vercel.app/c/join 을 엽니다. 아이폰은 "홈 화면에 추가"를 한 뒤 아이콘으로 다시 엽니다.

2. 우리 조 코드를 넣고 남편(또는 아내)을 골라 시작하기를 누릅니다. 홈의 "알림 켜기"를 누르고 허용합니다.

3. 컴퓨터 크롬에서 afpk-dongunghap.vercel.app/p/couples 를 열고 설계사 코드로 들어갑니다. 왼쪽 아래 알림 켜기를 누르고 허용합니다.

4. 목록에서 우리 조 연습 부부의 질문 틀을 엽니다. 30칸이 모두 저장되어 있으면 정상입니다. 해당 없음을 시험하려고, 2주 "자녀 수" 칸(원래 1명) 옆의 "해당 없음" 버튼을 누르고 저장합니다. "저장됨 v2"가 되고 변경 이력에 예전 값(1명)이 남습니다.

### 2단계. 사이클 시작과 1주차 주택

5. 질문 틀 맨 아래에서 "분기마다"를 고르고 사이클 시작을 누릅니다.

6. 두 폰에 "이번 주 질문 5개가 열렸어요 · 주택" 알림이 오고, 홈에 "1주차 · 주택 · 5문항"이 보이면 정상입니다.

7. 질문 화면에 계획 값이 보이지 않는지 봐 주세요. 남편은 위 정답대로 5문항을 모두 답합니다.

8. 아내는 "내 집 마련 시기"에 2034를 적습니다. "마련하고 싶은 집값"은 "말로 적기"를 눌러 "4억 8천"이라고 적습니다. 나머지는 정답대로 답합니다.

9. 둘 다 끝나면 컴퓨터에 "처리 대기 1건" 알림이 옵니다. 처리 대기에 "내 집 마련 시기" 한 건만 올라와 있어야 합니다. 계획 2032년, 남편 "2032년 · 계획과 같음", 아내 "2034년 · 다름"으로 보이면 정상입니다. 말로 적은 집값(4억 8천)은 계획과 같아서 올라오지 않습니다. 메모를 한 줄 적고 확인함을 누릅니다.

10. 왼쪽 사이클 화면에서 1주차가 "끝남"으로, 아래 "이번 사이클에서 어긋난 것"에 확인함과 메모가 보이면 정상입니다.

### 3단계. 다음 주, 그리고 답하지 않았을 때

11. 사이클 화면에서 "다음 주로 넘기기 (테스트용)"를 누릅니다. 두 폰에 출산/육아 알림이 옵니다.

12. 남편만 2주차 5문항을 정답대로 답합니다. "아이는 몇 명"은 "해당 없음"을 고릅니다. 아내는 아직 답하지 않습니다.

13. "다음 주로 넘기기"를 한 번 더 누릅니다. 3주차 노후가 열리고, 아내 폰에만 "아직 답하지 않은 질문이 남아 있어요" 알림이 오면 정상입니다.

14. 아내 폰 홈에 "지난주 질문이 남아 있어요 · 2주차 · 출산/육아"가 먼저 보입니다. 아내는 "아이는 몇 명"에 1을 적고, 나머지는 정답대로 답합니다.

15. 처리 대기에 "자녀 수"가 올라오면 정상입니다. 정답은 해당 없음인데 아내가 1명이라고 답해서, 새로 생긴 계획으로 잡힌 것입니다.

### 4단계. 상담 요청

16. 사이클 화면에서 상담 요청 보내기를 누르고, 6주가 안 지났다고 묻는 창에서 확인을 누릅니다.

17. 두 폰에 "설계사님이 상담을 요청했어요" 알림이 오고, 사이클 화면에 다음 사이클 날짜(3개월 뒤)가 보이면 정상입니다.

## 봐 주셨으면 하는 것

- 질문 문장을 처음 보는 사람도 바로 이해할 수 있는지
- 보기에 빠진 답이 없는지 (고를 게 없어서 "말로 적기"를 눌렀다면 어느 질문이었는지)
- 금액을 만 원 단위로 적는 게 헷갈리지 않는지
- "해당 없음"과 "아직 모름"의 차이가 부부 입장에서 구분되는지
- 홈의 [내 설계] 탭에는 계획 값이 보입니다. 팀 결정으로 그대로 두었습니다. 답하기 전에 열어 보게 될 것 같은지도 알려 주세요
