- **설계사 코드** — 준호에게 따로 받습니다

## 새로 생긴 기능

### 1. 두 분께 질문 보내기

설계사가 물어볼 카드를 직접 골라 두 분 폰에 보냅니다. **한 번에 무조건 3장**입니다. 앱은 카드를 추천하지 않습니다. 이미 보낸 질문에 두 분이 다 답하기 전에는 새로 보낼 수 없습니다.

### 2. 폰 알림

처음 한 번 "알림 켜기"를 누르고 허용하면 아래 알림이 옵니다. 알림에는 판정, 상대의 답, 금액을 넣지 않습니다. 잠금 화면에 그대로 보이기 때문입니다.

| 받는 사람 | 언제 | 알림 문구 |
|---|---|---|
| 부부 | 설계사가 질문을 보낼 때 | 설계사님이 질문 3개를 보냈어요 |
| 부부 | "두 분께 같이 묻기"를 할 때 | 설계사님이 확인 질문 1개를 보냈어요 |
| 부부 | 설계사가 엑셀로 계획을 고칠 때 | 설계사님이 [내 설계]를 새로 고쳤어요 |
| 설계사 | 고객이 "바뀐 게 있어요"를 보낼 때 | ○○ 부부 · 먼저 알린 변화 1건 |
| 설계사 | 두 분이 다 답했는데 어긋난 게 있을 때 | ○○ 부부 · 처리 대기 N건 |

> 아이폰은 홈 화면에 추가한 돈궁합 아이콘으로 열었을 때만 알림을 받습니다 (iOS 16.4 이상). 카톡 안에서 연 화면은 알림을 받지 못합니다.

### 3. 바뀐 게 있어요

이직, 임신처럼 사정이 바뀌면 고객이 질문을 기다리지 않고 [내 설계]에서 바로 설계사에게 알립니다. 배우자에게는 보이지 않습니다. 설계사는 처리 대기에서 셋 중 하나로 닫습니다.

- **두 분께 같이 묻기** — 그 카드 한 문항으로 두 분께 묻습니다 (이때만 1문항)
- **재설계 필요** — 엑셀에서 다시 설계합니다
- **상담 때 다루기** — 다음 상담 안건으로 남깁니다
### 4. 엑셀 다시 읽기

설계사가 엑셀에서 계획을 고쳐 저장하고 "엑셀 다시 읽기"만 누르면, 앱이 **바뀐 숫자만** 골라 보여 줍니다. 반영하면 새 버전이 되고, 예전 값은 변경 이력에 남습니다. 파일 연결은 컴퓨터의 크롬 · 엣지에서만 됩니다.

### 5. 엑셀은 한 파일

재무상태표와 현금흐름표가 한 파일에 들어 있는 엑셀 하나만 올립니다 ("파일 선택" 버튼). 숫자는 AI를 거치지 않고 칸에 적힌 그대로 옮깁니다.

### 6. 다 답한 뒤 홈 화면

내 답을 다 보내면 홈에 "답을 모두 보냈어요 · ○○님 차례예요"가 뜹니다.

## 테스트 순서

### 1단계. 준비 — 입장하고 알림 켜기

**남편 폰, 아내 폰 각각**

1. 사파리(아이폰) 또는 크롬(안드로이드)으로 afpk-dongunghap.vercel.app/c/join 을 엽니다. 카톡 안에서 열지 않습니다.

2. 아이폰이면 공유 버튼(네모에 위 화살표) → "홈 화면에 추가" → 홈 화면의 돈궁합 아이콘으로 다시 엽니다.

3. 우리 조 입장 코드 → 남편(또는 아내) → 시작하기.

4. 홈(맞춰보기 탭)의 "질문이 오면 알림 받기" → 알림 켜기 → 허용. 버튼이 사라지면 정상입니다.

**컴퓨터**

5. 크롬에서 afpk-dongunghap.vercel.app/p/couples → 왼쪽 칸에 설계사 코드 → 들어가기.

6. 왼쪽 아래 알림 켜기 → 허용. "알림 켜짐 ✓"으로 바뀌면 정상입니다.

7. 목록에서 우리 조 연습 부부 이름을 눌러 고릅니다.

### 2단계. 두 분께 질문 보내기

8. 왼쪽 질문 카드 → 맨 위 두 분께 질문 보내기 → 카드 줄을 눌러 3장 체크 (주택 취득 시점은 꼭 넣기) → 고른 3장으로 질문 보내기.

9. 두 폰에 "설계사님이 질문 3개를 보냈어요" 알림이 오면 정상입니다.

10. 알림을 눌러 답합니다. 남편은 모두 "네, 그대로예요". 아내는 주택 취득 시점만 "아니요, 바뀌었어요" → 2031년 3월, 나머지는 "네, 그대로예요".

11. 먼저 끝낸 사람의 홈에 "답을 모두 보냈어요 · ○○님 차례예요"가 보이면 정상입니다.

12. 둘 다 끝나면 컴퓨터에 "팀원 연습 N · 처리 대기 1건" 알림이 옵니다. 처리 대기에서 주택 취득 시점 🔴 부부 불일치를 확인하고 상담 때 다루기로 닫습니다.

### 3단계. 바뀐 게 있어요

13. 남편 폰: 내 설계 탭 → 주거 펼치기 → 주택 취득 시점 옆 바뀐 게 있어요 → 2031년 3월 → 설계사님께 알리기. 홈에 "설계사님께 전달됨"이 보이면 정상입니다.

14. 아내 폰: 같은 줄에 "전달됨"이 보이지 않으면 정상입니다 (배우자에게는 안 보임).

15. 컴퓨터에 "팀원 연습 N · 먼저 알린 변화 1건" 알림이 오면 정상입니다.

16. 처리 대기 맨 위 먼저 알린 변화 → 두 분께 같이 묻기. 두 폰에 "설계사님이 확인 질문 1개를 보냈어요" 알림이 오면 정상입니다. 둘 다 답합니다.

### 4단계. 엑셀 다시 읽기 (컴퓨터 크롬만)

17. 에이피_에피케_재무설계.xlsx 를 복사해 둡니다 (원본은 고치지 않기).

18. 부부 목록 → 아래 새 부부 → 파일 선택 → 복사한 엑셀. 이름이 채워지면 새 부부 등록하고 엑셀로 질문 카드 만들기.

19. 카드 후보 10개가 골라져 있으면 고른 10장 저장.

20. 엑셀로 만들기 → 이 컴퓨터 파일로 연결 → 같은 파일 → 크롬이 물으면 허용. "바뀐 숫자 0건"이면 정상입니다. 닫기.

21. 엑셀에서 남편 급여 숫자 하나만 바꿔 저장 → 질문 카드 맨 위 엑셀 다시 읽기. "바뀐 숫자 1건"이 나오면 반영합니다.

22. 변경 이력에 예전 값과 새 값이 함께 남아 있으면 정상입니다. 끝나면 그 부부를 지우기로 정리합니다.

## 알림이 안 올 때

| 확인할 것 | 어디서 |
|---|---|
| 아이폰을 홈 화면 아이콘으로 열었나 (사파리 탭 X) | 1단계 2번 |
| iOS 16.4 이상인가 | 설정 → 일반 → 정보 |
| 폰이 알림을 막지 않았나 | 설정 → 알림 → 돈궁합 (안드로이드는 크롬) |
| 컴퓨터 크롬이 알림을 막지 않았나 | 주소창 왼쪽 자물쇠 → 알림 → 허용 |
| "알림 켜기" 버튼이 안 보인다 | 카톡 안 브라우저일 수 있음 → 사파리 · 크롬으로 다시 |

알림이 몇 초에서 몇 분 늦게 올 수 있습니다. 알림이 안 와도 나머지 기능은 그대로 됩니다.
