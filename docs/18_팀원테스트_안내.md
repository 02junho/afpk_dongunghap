# 18. 팀원 테스트 안내 (11.04)

> 폰 한 대와 컴퓨터(크롬) 한 대로 20분이면 끝난다. 막히면 화면을 캡처해서 **몇 번 단계인지**와 함께 보내 주세요.
> 화면 맨 아래 작은 글씨 "버전 11.04"도 캡처에 나오게 찍어 주세요.

## 0. 내 연습 부부 고르기 — 한 사람에 하나씩

| 연습 부부 | 입장 코드 | 쓰는 사람 |
|---|---|---|
| 팀원 연습 1 | **893836** | |
| 팀원 연습 2 | **241403** | |
| 팀원 연습 3 | **430794** | |
| 팀원 연습 4 | **245244** | |

- **다른 사람의 코드로 들어가지 마세요.** 같은 코드에 같은 역할(남편/아내)로 두 사람이 들어오면, 나중에 들어온 사람이 자리를 가져가고 먼저 들어온 폰은 끊긴다.
- 연습용 "남편 · 아내"(482913)는 준호가 시연 준비에 쓴다. 테스트에는 위 네 개만 쓴다.
- 설계사 화면에 들어갈 **설계사 코드**는 준호에게 따로 받는다 (문서에 적지 않는다).

## 1. 준비 — 입장하고 알림 켜기 (5분)

**폰**
1. 폰에서 **afpk-dongunghap.vercel.app/c/join** 을 연다. 카톡 안에서 열지 말고 **사파리(아이폰) · 크롬(안드로이드)** 으로 연다.
2. **아이폰이면 먼저 홈 화면에 추가한다** — 화면 아래 공유 버튼(네모에 위 화살표) → "홈 화면에 추가" → 홈 화면의 **돈궁합 아이콘으로 다시 연다.** (아이폰은 이렇게 열어야 알림을 받는다. 안드로이드는 안 해도 된다)
3. 내 입장 코드 6자리 → **남편** → **시작하기**.
4. 홈(맞춰보기 탭)의 **질문이 오면 알림 받기 → 알림 켜기** → 폰이 물으면 **허용**. 버튼이 사라지면 정상.

**컴퓨터**
5. 크롬에서 **afpk-dongunghap.vercel.app/p/couples** → 왼쪽 칸에 설계사 코드 → **들어가기**.
6. 왼쪽 아래 **알림 켜기** → 크롬이 물으면 **허용**. **"알림 켜짐 ✓"** 으로 바뀌면 정상.
7. 목록에서 **내 연습 부부** 이름을 눌러 고른다.

## 2. 폰 — 두 분이 따로 답하기

8. 홈에 "이제부터 시작할게요 · 첫 맞춰보기 3문항" → **시작하기**.
9. 남편: 세 문항 모두 **네, 그대로예요** → **제출**. "아내님이 아직 답하는 중이에요" → **닫기**.
10. 홈에 **"답을 모두 보냈어요 · 아내님 차례예요"** 가 보이면 정상.
11. 홈 맨 아래 **다시 입장하기** → 코드가 채워져 있다 → **아내** → **시작하기** → **시작하기**.
12. 아내: 첫 문항(주택 취득 시점)은 **아니요, 바뀌었어요** → 연도 **2031**, 월 **3월** → **제출**. 나머지 두 문항은 **네, 그대로예요**.
13. **"두 분 답변이 설계사님께 전달됐어요"** 가 나오면 정상. 판정 결과는 폰에 안 나온다 (일부러 그렇다).

> 폰이 두 대면 한 대는 남편, 한 대는 아내로 들어가도 된다. 이때는 두 폰 모두 4번처럼 알림을 켠다.

## 3. 컴퓨터 — 처리 대기 알림과 확인

14. 컴퓨터에 **"팀원 연습 N · 처리 대기 1건"** 알림이 오면 정상. (몇 초~몇 분 걸릴 수 있다)
15. 알림을 누르거나 왼쪽 **처리 대기** → **주택 취득 시점 · 🔴 부부 불일치**. 남편 "2029년 6월" / 아내 "2031년 3월"이 나란히 보인다.
16. **상담 때 다루기**를 눌러 닫아 본다.

## 4. 컴퓨터 → 폰 — 두 분께 질문 보내기

17. 왼쪽 **질문 카드** → 맨 위 **두 분께 질문 보내기**.
18. 카드 줄을 눌러 **3장** 체크 (3장이 되면 나머지는 흐려진다) → **고른 3장으로 질문 보내기**.
19. 폰에 **"설계사님이 질문 3개를 보냈어요"** 알림이 오면 정상. 눌러서 2번처럼 남편 · 아내로 답한다.
    - 화면 위 **카톡 알림 문구 복사**는 알림을 안 켠 고객에게 카톡으로 보낼 문구다. 눌러서 메모장에 붙여 봐도 된다.

## 5. 폰 → 컴퓨터 — "바뀐 게 있어요"

20. 폰 홈 → **내 설계** 탭 → **주거** 를 눌러 펼친다.
21. "주택 취득 시점" 옆 **바뀐 게 있어요** → 2031년 3월 → **설계사님께 알리기**.
22. 홈으로 돌아가 그 줄에 **"설계사님께 전달됨"** 이 보이면 정상.
23. 컴퓨터에 **"팀원 연습 N · 먼저 알린 변화 1건"** 알림이 오면 정상.
24. 처리 대기 맨 위 **먼저 알린 변화**에서 **두 분께 같이 묻기** → 폰에 **"설계사님이 확인 질문 1개를 보냈어요"** 알림이 오면 정상.
    - 아직 답하지 않은 질문이 남아 있으면 "끝난 뒤 다시"라고 나온다. 폰에서 남은 질문을 먼저 끝낸다.

## 6. (선택) 컴퓨터 — 엑셀로 질문 카드 만들기

25. 설계사 화면 **부부 목록** → 아래 **새 부부** → **파일 선택** → `에이피_에피케_재무설계.xlsx`.
26. 이름(에이피 · 에피케)이 채워지면 **새 부부 등록하고 엑셀로 질문 카드 만들기**.
27. 카드 후보가 나오고 10개가 골라져 있으면 정상. 금액이 엑셀과 같은지 몇 개만 본다 (남편 급여 6,700만 · 월세 1,140만 등).
28. **고른 10장 저장** → 맨 위 **두 분께 질문 보내기**로 엑셀 카드 3장(예: 남편 급여 · 월세 · 보증금)을 골라 보낼 수 있다.
29. 끝나면 부부 목록에서 그 부부를 **지우기**.

## 알림이 안 올 때

| 확인할 것 | 어디서 |
|---|---|
| 아이폰을 **홈 화면 아이콘**으로 열었나 (사파리 탭 X) | 1번 2단계 |
| iOS 16.4 이상인가 | 설정 → 일반 → 정보 → iOS 버전 |
| 폰이 알림을 막고 있지 않나 | 설정 → 알림 → 돈궁합 (안드로이드는 크롬) |
| 컴퓨터 크롬이 알림을 막고 있지 않나 | 주소창 왼쪽 자물쇠 → 알림 → 허용 |
| "알림 켜기" 버튼이 안 보인다 | 카톡 안 브라우저일 수 있다 → 사파리 · 크롬으로 다시 연다 |

알림이 안 와도 앱의 나머지는 그대로 된다. 안 온 단계 번호와 폰 종류 · iOS 버전을 알려 주세요.

## 알아 두면 좋은 것

- 한 번 제출한 답은 고칠 수 없다. 다시 하려면 17번(두 분께 질문 보내기).
- 알림에는 판정 · 상대의 답 · 금액이 나오지 않는다. 일부러 그렇다 (잠금 화면에 보이기 때문).
- 설계사 화면은 컴퓨터로 연다. 폰으로 열면 좁아서 보기 어렵다.
- 앱이 무엇을 왜 그렇게 하는지는 `docs/11_화면흐름도.pdf` 에 있다.
