# 돈궁합 새 방향 테스트 안내 (11.05)

앱이 새 방향으로 바뀌었습니다. 재무설계 결과를 6테마 × 5문항 질문 틀에 담고, 매주 테마 하나씩 두 분께 묻습니다. 두 명이 한 조로 20분이면 끝납니다.

## 준비물

- **폰 2대** — 한 명은 남편, 한 명은 아내로 들어갑니다
- **컴퓨터 1대 (크롬)** — 설계사 화면
- **설계사 코드** — 준호에게 따로 받습니다

| 조 | 연습 부부 | 입장 코드 | 쓰는 사람 |
|---|---|---|---|
| 1조 | 팀원 연습 1 | 242311 |  |
| 2조 | 팀원 연습 2 | 739899 |  |

> 두 연습 부부 모두 질문 틀 30칸이 예시 값으로 채워져 있고, 사이클은 아직 시작 전입니다. 다른 조의 코드로 들어가지 마세요 (같은 역할로 두 명이 들어오면 나중 사람이 자리를 가져갑니다).

## 바뀐 것

### 1. 질문 틀 — 6테마 × 5문항 = 30칸

주택 · 출산/육아 · 노후 · 보험 · 부채 · 투자. 틀은 모든 고객이 같고, 고객마다 **계획 값**만 다릅니다. 설계사 화면 왼쪽 **질문 틀**에서 봅니다.

### 2. Word에서 채우기

재무설계 결과 Word를 올리면 AI가 30칸의 계획 값을 찾아 **Word 원문과 함께** 보여 줍니다. 설계사가 칸마다 **"원문과 맞음"**을 눌러야 저장됩니다. 숫자 · 날짜는 AI가 아니라 앱의 규칙이 바꿉니다. (Word 양식이 정해지면 시험합니다 — 이번에는 "예시 값으로 채우기"로 대신합니다)

### 3. 6주 사이클

설계사가 **사이클 시작**을 누른 날부터 7일마다 다음 테마 5문항이 두 분 폰에 열립니다. 6주에 한 바퀴, 분기 또는 반기마다 다시 돕니다.

- 그 주에 답하지 않으면 질문이 닫히지 않고 남습니다 — 홈에 **"지난주 질문이 남아 있어요"**
- 열린 지 4일이 지났는데 안 한 분에게만 **알림이 한 번 더** 갑니다
- 6주가 끝나면 설계사가 **상담 요청 보내기** → 두 분 폰에 알림
### 4. 설계사 화면

| 메뉴 | 하는 일 |
|---|---|
| 질문 틀 | 30칸 계획 값 보기 · 고치기 · Word에서 채우기 · 사이클 시작 |
| 처리 대기 | 계획과 어긋난 답. 버튼은 "확인함"과 "이건 같은 뜻이에요"(AI 오판) 두 개 |
| 사이클 | 주차별 진행(남편 n/5 · 아내 n/5), 이번 사이클에서 어긋난 것(확인 ✓ · 메모), 다음 주로 넘기기(테스트용), 상담 요청 보내기 |
| 변경 이력 | 계획 값이 바뀐 기록 |

### 5. 뺀 것

엑셀 올리기 · 엑셀 다시 읽기 · 카드 직접 추가 · 질문 3장 고르기 · "바뀐 게 있어요".

## 테스트 순서

### 1단계. 준비

1. 남편 폰 · 아내 폰: 사파리(아이폰) 또는 크롬(안드로이드)으로 afpk-dongunghap.vercel.app/c/join. 아이폰은 "홈 화면에 추가" → 아이콘으로 다시 엽니다.

2. 우리 조 코드 → 남편(또는 아내) → 시작하기. 홈의 "질문이 오면 알림 받기 → 알림 켜기" → 허용.

3. 컴퓨터: 크롬에서 afpk-dongunghap.vercel.app/p/couples → 설계사 코드 → 들어가기 → 왼쪽 아래 알림 켜기 → 허용.

4. 목록에서 우리 조 연습 부부 → 질문 틀. 30칸이 "저장됨 v1"로 보이면 정상입니다. 아무 칸 하나를 고쳐 저장하면 "저장됨 v2"가 되고, 변경 이력에 예전 값이 남습니다.

### 2단계. 사이클 시작 → 1주차 주택

5. 질문 틀 맨 아래 분기마다 → 사이클 시작.

6. 두 폰에 "이번 주 질문 5개가 열렸어요 · 주택" 알림 ✓. 홈에 "1주차 · 주택 · 5문항".

7. 남편은 모두 "네, 그대로예요". 아내는 "내 집 마련 시점"만 "아니요, 바뀌었어요" → 보기에서 2034년 6월을 고르고, 나머지는 "그대로예요". (맞는 보기가 없으면 맨 끝 "기타 — 직접 적기")

8. 둘 다 끝나면 컴퓨터에 "팀원 연습 N · 처리 대기 1건" 알림 ✓. 처리 대기에서 🔴 계획과 다름 (아내: 바뀜 → 2034년 6월) → 메모 한 줄 → 확인함.

9. 왼쪽 사이클: 1주차 "끝남", 아래 "이번 사이클에서 어긋난 것"에 ✓ 확인함과 메모가 보이면 정상입니다.

### 3단계. 다음 주 · 답 안 하면

10. 사이클 화면 → 다음 주로 넘기기 (테스트용). 두 폰에 "출산/육아" 알림 ✓.

11. 남편만 2주차 5문항에 답하고, 아내는 답하지 않습니다.

12. 다음 주로 넘기기를 한 번 더 → 3주차 노후가 열리고, 아내 폰에만 "아직 답하지 않은 질문이 남아 있어요" 알림 ✓.

13. 아내 폰 홈에 "지난주 질문이 남아 있어요 · 2주차 · 출산/육아"가 먼저 보이면 정상입니다. 답하면 3주차로 넘어갑니다.

### 4단계. 상담 요청

14. 사이클 화면 → 상담 요청 보내기 → (6주 전이라 묻는 창) 확인.

15. 두 폰에 "설계사님이 상담을 요청했어요" 알림 ✓. 사이클 화면에 "다음 사이클 (3개월 뒤 날짜)"가 보이면 정상입니다.
