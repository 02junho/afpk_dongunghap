# 18. 팀원 테스트 안내 (11.04)

> 폰 한 대와 컴퓨터 한 대로 15분이면 끝난다. 막히면 화면을 캡처해서 **몇 번 단계인지**와 함께 보내 주세요.
> 화면 맨 아래 작은 글씨 "버전 11.04"도 캡처에 나오게 찍어 주세요.

## 0. 내 연습 부부 고르기 — 한 사람에 하나씩

| 연습 부부 | 입장 코드 | 쓰는 사람 |
|---|---|---|
| 팀원 연습 1 | **893836** | |
| 팀원 연습 2 | **241403** | |
| 팀원 연습 3 | **430794** | |
| 팀원 연습 4 | **245244** | |

- **다른 사람의 코드로 들어가지 마세요.** 같은 코드에 같은 역할(남편/아내)로 두 사람이 들어오면, 나중에 들어온 사람이 자리를 가져가고 먼저 들어온 폰은 끊긴다.
- 연습용 "남편 · 아내"(482913)는 준호가 시연 준비에 쓴다. 테스트에는 위 네 개만 쓴다.
- 설계사 화면에 들어갈 **설계사 코드**는 준호에게 따로 받는다 (문서에 적지 않는다).

## 1. 폰 — 남편으로 답하기 (5분)

1. 폰 브라우저에서 **afpk-dongunghap.vercel.app/c/join** 을 연다.
2. 내 입장 코드 6자리 → **남편** → **시작하기**.
3. 홈에 "이제부터 시작할게요 · 첫 맞춰보기 3문항"이 보이면 **시작하기**.
4. 세 문항 모두 **네, 그대로예요** → **제출**.
5. "아내님이 아직 답하는 중이에요"가 나오면 **닫기**.
6. 홈에 **"답을 모두 보냈어요 · 아내님 차례예요"** 가 보이면 정상.

## 2. 같은 폰 — 아내로 답하기

7. 홈 맨 아래 **다시 입장하기** → 코드가 채워져 있다 → **아내** → **시작하기**.
8. 첫 문항(주택 취득 시점)은 **아니요, 바뀌었어요** → 연도 **2031**, 월 **3월** → **제출**.
9. 나머지 두 문항은 **네, 그대로예요** → **제출**.
10. **"두 분 답변이 설계사님께 전달됐어요"** 가 나오면 정상. 판정 결과는 폰에 안 나온다 (일부러 그렇다).

> 폰이 두 대면 한 대는 남편, 한 대는 아내로 들어가도 된다.

## 3. 컴퓨터 — 설계사 화면 (크롬)

11. **afpk-dongunghap.vercel.app/p/couples** → 왼쪽 칸에 설계사 코드.
12. 목록에서 **내 연습 부부** → **처리 대기**.
13. **주택 취득 시점 · 🔴 부부 불일치** 가 올라와 있으면 정상. 남편 "2029년 6월" / 아내 "2031년 3월"이 나란히 보인다.
14. **상담 때 다루기**를 눌러 닫아 본다.
15. 한 번 더 하고 싶으면 처리 대기 맨 아래 **두 분께 질문 보내기** → 카드 3장 고르기 → 폰에서 1번부터 다시.

## 4. 폰 — "바뀐 게 있어요"

16. 폰 홈 → **내 설계** 탭 → **주거** 를 눌러 펼친다.
17. "주택 취득 시점" 옆 **바뀐 게 있어요** → 2031년 3월 → **설계사님께 알리기**.
18. 홈으로 돌아가 그 줄에 **"설계사님께 전달됨"** 이 보이면 정상.
19. 컴퓨터 처리 대기 맨 위 **먼저 알린 변화**에 올라와 있으면 정상. **상담 때 다루기**로 닫는다.
   - "두 분께 같이 묻기"는 맞춰보기가 열려 있으면 "끝난 뒤 다시"라고 나온다. 정상이다.

## 5. (선택) 컴퓨터 — 엑셀로 질문 카드 만들기

20. 설계사 화면 **새 부부** → **파일 선택** → `에이피_에피케_재무설계.xlsx`.
21. 이름(에이피 · 에피케)이 채워지면 **새 부부 등록하고 엑셀로 질문 카드 만들기**.
22. 카드 후보가 나오고 10개가 골라져 있으면 정상. 금액이 엑셀과 같은지 몇 개만 본다 (남편 급여 6,700만 · 월세 1,140만 등).
23. **고른 10장 저장**.
24. 저장한 뒤 맨 위 **두 분께 질문 보내기**로 엑셀 카드 3장(예: 남편 급여 · 월세 · 보증금)을 골라 보낼 수 있다. 끝나면 그 부부를 **지우기**.

## 6. 컴퓨터 + 폰 — 두 분께 질문 보내기와 알림

25. 폰 홈(맞춰보기 탭)의 **질문이 오면 알림 받기 → 알림 켜기** → 폰이 물으면 **허용**.
    - 아이폰은 **홈 화면에 추가한 돈궁합 아이콘으로 열어야** 이 버튼이 나온다 (사파리 탭에서는 안 나온다).
26. 컴퓨터 설계사 화면 왼쪽 아래 **알림 켜기** → 크롬이 물으면 **허용**.
27. 컴퓨터: 내 연습 부부 → **질문 카드** → 맨 위 **두 분께 질문 보내기** → 카드 3장 체크 → **고른 3장으로 질문 보내기**.
    - 진행 중인 질문이 있으면 "두 분이 다 답한 뒤 보낼 수 있습니다"가 나온다. 정상이다. 먼저 1~2번처럼 답을 끝낸다.
28. 폰에 **"설계사님이 질문 3개를 보냈어요"** 알림이 오면 정상. 눌러서 남편 · 아내로 답한다 (하나는 다르게).
29. 두 분이 다 답하면 컴퓨터에 **"팀원 연습 N · 처리 대기 1건"** 알림이 오면 정상.
30. 폰에서 "바뀐 게 있어요"를 보내면 컴퓨터에 **"먼저 알린 변화 1건"** 알림이 오면 정상.

> 알림이 몇 초~몇 분 늦게 올 수 있다. 안 오면 폰 설정 → 알림 → 돈궁합(또는 크롬)이 켜져 있는지 본다.

## 알아 두면 좋은 것

- 한 번 제출한 답은 고칠 수 없다. 다시 하려면 15번.
- 알림을 켜려면 먼저 DB 패치(`supabase/patch-2026-11-04-push.sql`)가 실행돼 있어야 한다 — 준호가 한다.
- 폰에서 "홈 화면에 추가"는 안 해도 테스트에는 상관없다.
- 컴퓨터 설계사 화면을 폰으로 열면 좁아서 보기 어렵다. 컴퓨터로 연다.
- 앱에서 무엇이 왜 그렇게 동작하는지는 `docs/11_화면흐름도.pdf` 에 있다.
