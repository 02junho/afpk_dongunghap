# 21. 새 방향 — 6테마 · 6주 사이클 (11.04 결정)

> 이 문서가 앞의 맞춰보기 방식(`docs/19` 카드 골라 보내기 등)을 대신한다. 질문 틀은 `docs/20`.
> **11.04 앱에 반영했다.** DB 패치 `supabase/patch-2026-11-04-cycles.sql` 실행 필요. 아래 "5번"은 만든 그대로 고쳐 적었다.

## 흐름

```
① 설계사: 재무설계 결과(Word)를 올린다
② AI: Word에서 30문항 틀의 계획 값을 찾아 넣는다 → 설계사가 원문과 하나씩 대조해 확인
③ 설계사: "사이클 시작" — 이날부터 1주차
④ 매주 그 주 테마 5문항이 두 분 폰에 열린다 (알림)
⑤ 답이 계획과 다르면 설계사 처리 대기에 쌓인다
⑥ 6주가 끝나면 설계사가 6주치를 보고 "상담 요청" 알림을 보낸다
⑦ 고객에 따라 분기 또는 반기 뒤 다시 1주차부터
```

## 정한 것 (11.04)

| # | 정한 것 | 결정 |
|---|---|---|
| 1 | 6테마에 없는 주제 | 연결되는 테마에 넣는다 (소득 → 출산/육아 · 노후, 양가 지원 → 주택 · 부채, 세금 → 노후 · 부채). 결혼은 뺀다 |
| 2 | 30문항 | 예전 카드 틀 28장을 6테마 × 5문항으로 다시 짠다 → `docs/20` |
| 3 | Word 모양 | 나중에 받는다 |
| 4 | 매주 질문 | **사이클을 시작한 날 기준 7일**마다 다음 테마 |
| 5 | 한 분이 그 주에 답하지 않으면 | **둘 다** — 알림을 한 번 더 보내고, 그래도 안 하면 다음 주로 넘긴다 |
| 6 | 처리 대기 | "확인함"으로 남긴다 (아래) |
| 7 | "바뀐 게 있어요" | **뺀다** — 매주 묻게 되어 겹친다 |
| 8 | 시연 · 테스트 | 설계사 화면에 **"다음 주로 넘기기"** 버튼 |

## 5번을 앱에서 어떻게 할지 (제안)

- 질문이 열린 지 **4일**이 지났는데 다 답하지 않은 분에게만 알림 한 번 더: "아직 답하지 않은 질문이 남아 있어요".
- 다음 주가 돼도 답하지 않은 주의 질문은 **닫지 않고 남겨 둔다.** 부부 홈에 "지난주 질문이 남아 있어요"로 먼저 보이고, 다 하면 이번 주 질문으로 넘어간다. 이미 답한 분은 다시 답하지 않는다.
- 사이클 정리 화면에 주차마다 "남편 5/5 · 아내 0/5"처럼 보인다. 상담 요청을 보내면 남은 질문도 닫힌다 — 상담에서 직접 묻는다.
- "때가 됐나"는 부부 홈을 열 때 · 설계사 화면을 볼 때 · 하루 한 번(오전 9시) 예약 실행으로 확인한다.

## 6번 "확인함"을 어디에 남길지 (제안)

| 어디 | 무엇이 보이나 |
|---|---|
| **처리 대기** — 카드마다 | 버튼은 **확인함** 하나와 **같은 뜻이에요**(AI 오판 기록)만. 메모 한 줄 (선택) |
| **사이클 정리** — 새 화면 | 이번 6주에 어긋난 것 전부를 테마별로. 확인한 것에는 ✓ 와 메모. 맨 아래 **상담 요청 보내기** |
| 변경 이력 | 그대로 — 계획 값이 바뀐 기록만 |

"확인함"은 판정을 바꾸지 않는다. 설계사가 봤다는 표시와 메모가 남고, 상담 때 사이클 정리 화면을 그대로 보며 이야기한다.
부부에게는 여전히 판정도 확인 여부도 보이지 않는다. "상담 요청" 알림만 간다.

## 새로 들어오는 것

Word 올리기 + AI가 계획 값 찾기(설계사 확인) · 30문항 고정 틀 · 사이클 시작 · 주차별 자동 열기 · 답 독촉 알림 · 다음 주로 넘기기(시연용) · 사이클 정리 화면 · 상담 요청 알림 · 부부마다 주기(분기 / 반기)

## 기술서 · 제출 글에서 바뀌는 것

- **"엑셀 숫자는 AI를 거치지 않는다"가 더는 맞지 않는다.** AI가 Word에서 계획 값을 옮긴다. 대신 "AI는 찾아 옮기기만 하고, 값마다 원문과 함께 설계사가 확인해야 저장된다"로 바꾼다.
- AI가 하는 일: 답의 뜻 비교 · 세 줄 요약 · **Word에서 계획 값 찾기** (세 가지).
- Word에서 값을 얼마나 정확히 찾는지 정답과 대조해 재야 한다 (가상고객 Word 1개 → 30칸 정답표).
